久々のリコリモで銀河撮影 〜 銀河画像を改善

 September 21, 2026に投稿  |  

はじめに

リコリモでの天体撮影は、観測装置メンテナンスのため4ヶ月間中断してたが、ようやく最近再開された。天候に恵まれ一週間前に撮影ができた。この週末画像処理を行ったので、その結果をまとめる。スクリプトで自動的に画像を得る手順、およびGUIで改善する部分に注目されたい。

関連情報

リコリモ、sirilについては以前のこの記事に関連リンクがある。

画像処理

1. 撮影対象の選択・経緯

散光星雲、銀河で撮影対象をChatGPTを使いながら決めていった。先ずは、散光星雲からはタランチュラ星雲（NGC2070）を対象に選び、次の候補は、棒渦巻銀河・NGC1097を対象と考えた。

タランチュラ星雲は、Hα/SII/OIIIフィルターを使ったSHOナローバンドで撮影しようと9/13に観測予約を入れた。NGC1097は、LRGB + Hαで撮影することとし、翌日9/14に予約を入れた。

結果、9/13は天候の関係で撮影できず、リベンジで、9/16, 17に分けて予約したが、両日ともダメであった。NGC1097は、計画通り9/14に撮影ができた。

Sirilの使い方に慣れていない自分への備忘録も兼ねて、NGC1097の画像処理をここにまとめることにした。

2. 撮影データ

3. 前処理

(1) 作業ディレクトリを準備

この記事のスクリプトを参考に各フィルタの画像をL/R/G/B/Haディレクトに配置。

更に作業用のディレクトを作成する。

% mkdir -p work_L work_R work_G work_B work_Ha align_input align_work registered

ここで、次のような構造となっている。

NGC1097/
  L/       L_001.fit, L_002.fit, ...
  R/       R_001.fit, R_002.fit, ...
  G/       G_001.fit, G_002.fit, ...
  B/       B_001.fit, B_002.fit, ...
  Ha/      Ha_001.fit, Ha_002.fit, ...
  work_L/
  work_R/
  work_G/
  work_B/
  work_Ha/
  align_input/
  align_work/
  registered/
  01_stack.ssf
  02_align_rgb.ssf
  03_lrgb.ssf
  04_ha_lrgb.ssf

0[1-4]_*ssfはsiril用のスクリプトで各々次の通り。

01_stack.ssf 〜 各フィルタの画像をスタッキングする
requires 1.4.4
setext fit
set32bits
setcompress 0

# L
cd L
convert L -out=../work_L
cd ../work_L
register L
stack r_L rej w 3 3 -norm=add -32b -out=../L_stacked
cd ..
load L_stacked
mirrorx -bottomup
save L_stacked
save align_input/channel_00001

# R
cd R
convert R -out=../work_R
cd ../work_R
register R
stack r_R rej w 3 3 -norm=add -32b -out=../R_stacked
cd ..
load R_stacked
mirrorx -bottomup
save R_stacked
save align_input/channel_00002

# G
cd G
convert G -out=../work_G
cd ../work_G
register G
stack r_G rej w 3 3 -norm=add -32b -out=../G_stacked
cd ..
load G_stacked
mirrorx -bottomup
save G_stacked
save align_input/channel_00003

# B
cd B
convert B -out=../work_B
cd ../work_B
register B
stack r_B rej w 3 3 -norm=add -32b -out=../B_stacked
cd ..
load B_stacked
mirrorx -bottomup
save B_stacked
save align_input/channel_00004

# Ha
cd Ha
convert Ha -out=../work_Ha
cd ../work_Ha
register Ha
stack r_Ha rej w 3 3 -norm=add -32b -out=../Ha_stacked
cd ..
load Ha_stacked
mirrorx -bottomup
save Ha_stacked
save align_input/channel_00005
02_align_rgb.ssf 〜 スタックした画像の位置合わせ・RGB合成
requires 1.4.4
setext fit
set32bits
setcompress 0
cd align_input
convert master -out=../align_work
cd ../align_work
register master -2pass
seqapplyreg master -framing=min
load r_master_00001
save ../registered/L_registered
load r_master_00002
save ../registered/R_registered
load r_master_00003
save ../registered/G_registered
load r_master_00004
save ../registered/B_registered
load r_master_00005
save ../registered/Ha_registered
cd ../registered
rgbcomp R_registered G_registered B_registered -out=RGB_linear
03_lrgb.ssf 〜 LRGB合成
requires 1.4.4
setext fit
set32bits
setcompress 0
cd registered
load RGB_linear
autostretch
save RGB_stretched
load L_registered
autostretch
save L_stretched
rgbcomp -lum=L_stretched RGB_stretched -out=LRGB
04_ha_lrgb.ssf 〜 Ha混合（HaをRに線形マッチし、赤へ20%混合）
requires 1.4.4
setext fit
set32bits
setcompress 0
cd registered
load RGB_linear
split R_base G_base B_base
load Ha_registered
linear_match R_base 0.001 0.8
save Ha_matched
pm "0.8*$R_base$+0.2*$Ha_matched$"
save R_Ha
rgbcomp R_Ha G_base B_base -out=HaRGB_linear
load HaRGB_linear
autostretch
save HaRGB_stretched
load L_registered
autostretch
save L_stretched
rgbcomp -lum=L_stretched HaRGB_stretched -out=HaLRGB

4. スクリプト実行

前処理で準備した、各フィルタ毎の撮影画像をスタッキング、合成する。

(1) フィルタ別スタッキング
% /Applications/Siril.app/Contents/MacOS/siril-cli -d "$PWD" -s "$PWD/01_stack.ssf"
(2) フィルタ間の位置合わせ・RGB合成
% /Applications/Siril.app/Contents/MacOS/siril-cli -d "$PWD" -s "$PWD/02_align_rgb.ssf"

ここで作成されるL_registered.fitはGUIでの背景補正で使用する。

(3) LRGB合成
% /Applications/Siril.app/Contents/MacOS/siril-cli -d "$PWD" -s "$PWD/03_lrgb.ssf"

LRGB.fitがスクリプト実行により作成されるLRGB画像。

(4) Ha混合
% /Applications/Siril.app/Contents/MacOS/siril-cli -d "$PWD" -s "$PWD/04_ha_lrgb.ssf"

HaLRGB.fitがスクリプト実行により作成されるHaを混合した画像。

ここで作成されるHaRGB_linear.fitはGUI操作（背景補正）で使用する。

スクリプトで作成される画像LRGB.fit、HaLRGB.fitは、バックグランドの暗さ不足で、モヤがかかっているようなので、GUIで背景補正を施す。

5. GUIよる調整（背景補正）

(1) 使用ファイル

registered フォルダ内の、次の2枚を使います。

ファイル 用途
HaRGB_linear.fit Hαを赤へ混ぜた、ストレッチ前のカラー画像
L_registered.fit 位置合わせ済みの、ストレッチ前のL画像
(2) Sirilで作業ディレクトリ指定、カラー画像を読み込む

Sirilを起動し、画面下部のコマンド入力欄に、次を入力して作業ディレクトリを指定。

cd "(ProperPathTo)/NGC1097/registered"

続けて、次を1行ずつ実行し、カラー画像を読み込む。

setext fit
set32bits
setcompress 0
load HaRGB_linear

HaRGB_linearを読み込むも、明るい星は表示されるが、銀河は表示されない。

ここで、Siril画面の下部中央の「線形」のプルダウンメニューから、「自動イコライゼーション」を選ぶ。

(3) Ha+RGBの背景を補正

Siril上部メニューの「画像処理」→「Background Extraction」を開く。「バックグラウンド抽出」で次の通り設定する。

設定項目 最初に試す設定
補間方法 RBF
Smoothing／平滑化 0.5、または50%
Samples per line／1行あたりのサンプル数 10
Grid tolerance／許容値 1.0
修正／Correction 引き算／Subtraction
Keep all samples／全サンプルを保持 オフ

設定後、「生成」を押すと、画面上に小さな四角が並ぶ。空の背景だけに小さな四角を置く。すなわち、g銀河の中心、渦巻きの腕、腕の外側に広がる淡い光の部分、明るい星やその周辺の光のにじみに重なる部分、等の小さな四角は消す。（右クリックで削除、左クリックで追加できる）

(4) 補正結果を確認・確定・保存

「バックグラウンドを計算」を押す。

補正結果を確認し、良ければ「適用」で確定する。

Sirilのコマンドラインに以下を入力し、別名で保存する。

save HaRGB_bg_linear
(5) L画像にも同様に背景補正

コマンドラインに次を実行し、L画像を読み込む。

load L_registered

「自動イコライゼーション」にし、手順(3)、(4)を実行して背景抽出を行う。

以下で、別名で保存する。

save L_bg_linear
(6) 背景目標値0.10で、ストレッチする

コマンドラインに以下を1行ずつ実行する。

load HaRGB_bg_linear
autostretch -2.8 0.10
save HaRGB_bg_stretched_010

同様にL画像。

load L_bg_linear
autostretch -2.8 0.10
save L_bg_stretched_010

ここで「自動イコライゼーション」を「線形」に戻す。

(7) Ha混合のLRGBを再合成

コマンドラインで次を実行。

rgbcomp -lum=L_bg_stretched_010 HaRGB_bg_stretched_010 -out=HaLRGB_bg_010
load HaLRGB_bg_010

再合成した結果を確認する。

暗すぎた場合は、(6)の手順で、0.10を0.15に変えて試す。この時、末尾の010を015とする。

(8) 背景をもう少し暗くする

次の手順で中間調を調整する。

load HaLRGB_bg_010
mtf 0 0.55 1

mtfの3つの数値の意味は次のとおり。

3つの数字は、順に黒点・中間調・白点です。

値 意味
0 黒点を動かさない
0.55 中間調を少し暗くする
1 白点を動かさない
(9) 結果を保存
save HaLRGB_bg_final

PNGで保存するには、次のとおり

load HaLRGB_bg_final
savepng NGC1097_HaLRGB_bg_final
